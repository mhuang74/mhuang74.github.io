你有沒有遇過視訊通話時，貓從鍵盤上走過去，在聊天室打出一串亂碼？或是好奇的小孩為了「幫忙」你的簡報，把畫面上看到的東西全點了一輪？HandsOff 就是為這種情況做的小工具。它擋掉所有鍵盤、觸控板和滑鼠輸入，螢幕則完全保持可見。

<!-- more -->

HandsOff 現在是一個選單列應用程式；它的開發和除錯過程，請看[打造 HandsOff 教我怎麼帶 coding agent](/zh-tw/posts/handsoff-steering-coding-agents)。

## 問題

現在的工作常常要你把筆電開著、東西繼續跑，人卻離開座位，或是在視訊通話裡。這就招來幾種麻煩狀況：

- 視訊會議。貓走過鍵盤，在你最不該靜音的時候把你靜音，或在聊天室打出一串沒意義的字。
- 簡報。你分享螢幕時，小孩或寵物去碰觸控板，亂點一通。
- 筆電放著沒人看。你想繼續盯著畫面上的某個東西，但不想讓誤觸打斷它。
- 公共場所。你短暫離開一下，擋掉隨手亂碰。

傳統的做法像是鎖定螢幕，會把一切都藏起來，剛好違背目的。HandsOff 換一種做法：擋掉輸入，但螢幕保持可見。

## HandsOff 怎麼運作

HandsOff 用 macOS CoreGraphics 的事件攔截（event tap），在系統層攔下鍵盤、觸控板和滑鼠事件。鎖定時螢幕持續亮著、看得到內容，但任何輸入都進不來，唯一的例外是你那組解鎖密語。

主要功能：

- 完全擋住輸入。螢幕維持可見，所有鍵盤、觸控板和滑鼠輸入都被擋下。
- 安全解鎖。你盲打密語來解鎖，沒有回顯、沒有游標。
- 自動鎖定。閒置 180 秒後自動鎖定，可設定在 20 到 600 秒之間。
- 說話快速鍵。鎖定時按 `Ctrl+Cmd+Shift+T`，會放行一次空白鍵，讓你在視訊通話裡解除靜音。
- 麥克風和攝影機照常運作。鎖定只影響輸入裝置。
- 只有一種模式。它就是原生的選單列應用程式，沒有別的東西。

## 主要使用情境

### 視訊會議

在家工作，身邊有寵物或小孩？HandsOff 在 Zoom、Google Meet 或 Teams 通話時保護你：

- 鎖住輸入，同時在鏡頭前保持可見。
- 用說話快速鍵解除靜音，不必解鎖。
- 貓可以走過鍵盤，不會造成災難。
- 就算忘記鎖定，自動鎖定也會保護你。

### 簡報與螢幕分享

分享螢幕的時候：

- 鎖住輸入，避免誤點或誤按。
- 讓簡報順順地播完，不被打斷。
- 需要互動時立刻解鎖。
- 用在 demo、教育訓練和客戶會議上都合適。

### 筆電放著沒人看

需要離開一下，但又想繼續盯著某個東西？

- 鎖住輸入，螢幕保持可見。
- 盯著跑很久的行程、build 或部署。
- 去拿杯咖啡時，看著視訊會議繼續進行。
- 在公共場所防止誤觸。

### 長時間的 build 與 agent session

coding agent 在跑測試或 build 時鎖住輸入。螢幕還看得清楚，你可以看著輸出長出來，誤按的鍵也打不斷這個 session。

## 開始使用

HandsOff 以 ad-hoc 簽署的 DMG 形式發布。

1. 從 [GitHub Releases](https://github.com/mhuang74/handsoff-rs/releases) 下載 arm64 或 x86_64 的 DMG。
2. 把 `HandsOff.app` 拖到 `/Applications`。
3. 第一次啟動時按右鍵選「打開」，然後確認 Gatekeeper 的提示。
4. 在系統設定裡授予輔助使用權限。
5. 第一次執行時會自動開啟設定精靈。

鎖定時選單列圖示是紅色的。選單裡有鎖定輸入、偏好設定、變更密語、重設、修正輔助使用權限、檢查更新、說明和結束。鎖定期間所有滑鼠點擊都被擋住，所以只能用密語解鎖。

## 安全性

HandsOff 把你按下的實體鍵碼做單向雜湊後儲存。這樣任何鍵盤配置都能用，而且磁碟上不會留下可讀的內容。

其他細節：

- 設定檔只有你的使用者帳號能讀。
- 不連網、沒有遙測。
- 所有資料都留在你的裝置上。
- 自動解鎖預設 60 分鐘，之後每次加倍，最多 24 小時。只有用密語解鎖才會重設它。

HandsOff 防的是隨手亂碰，不是防一個有心、能重開機、能砍掉應用程式或直接把機器搬走的本地攻擊者。

## 用 Rust 打造

HandsOff 用 Rust 寫成，兼顧效能、安全和原生 macOS 整合。它用 CoreGraphics 事件攔截來可靠地擋住輸入，也乾淨地接上 macOS 的輔助使用框架。

專案是開源的，放在 [GitHub](https://github.com/mhuang74/handsoff-rs) 上。歡迎貢獻。
